# p4_blood_bank_application
•	Developed CI/CD pipelines using Jenkins, integrating GitHub for source code management and SonarQube for code quality analysis.
•	Built and pushed Docker images for the Blood Bank application and MySQL database to Docker Hub.
•	Deployed the application using Docker Stack with an overlay network, configuring three application replicas and database connectivity.
•	Configured the Jenkins Controller-Agent architecture and integrated monitoring plugins to track pipeline execution and audit details; validated application functionality, including donor registration and donor search.
